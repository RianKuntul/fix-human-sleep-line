for the make.fun competition
[Fix Human Sleep: Funniest Patch Note](https://make.fun/bounty/u-yuki-kato-fix-human-sleep-funniest-patch-note-f6ad4c27).

## Run

```sh
node main.ts
```

Writes the entry line to `./output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set), with no trailing newline.
